# Frontend — Leñas y Sabores

React + TypeScript + Vite. Consultar el [README del proyecto](../README.md) para identidad visual, organización y distribución de ramas.

```bash
npm ci
npm run dev
```

- `npm run typecheck`: comprobar TypeScript.
- `npm run lint`: analizar el código con Oxlint.
- `npm run build`: comprobar tipos y compilar.
- `npm run preview`: servir la compilación.

Requiere Node.js 22.12 o superior. La pantalla inicial es un marcador de la base compartida; las interfaces se desarrollan en las ramas de cada módulo.
